## 확정한 요구사항

- 상단 바는 항상 불투명하며 조작과 드래그 이동이 가능하다.
- 편집 모드 OFF에서는 본문과 리사이즈 영역이 뒤 작업창 입력을 가로채지 않는다.
- 편집 모드 ON에서는 이미지와 창 크기를 조절할 수 있다.
- 전체·가로·세로 맞춤, 실제 크기, 수동 배율을 제공한다.

## 제안값 및 구현 시 확인 사항

- .NET 10과 기본 단축키 Ctrl+Alt+R/E를 채택했다. 충돌 시 Ctrl+Shift+F12/F11을 시도한다.
- 시작 및 재시작 편집 OFF, 초기 전체 맞춤, 수동 배율 5~1600%를 채택했다.
- 두 창 구조와 네이티브 스타일을 구현했다. 실제 다른 앱에 대한 마우스 입력 통과는 미검증이다.
- 오픈소스 라이선스는 미선택 상태다. 공개 저장소라는 이유만으로 임의 부여하지 않는다.
