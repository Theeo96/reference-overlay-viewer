- F04: 대형 이미지 반복 교체의 응답성과 장시간 메모리 사용. 크기 제한 및 비동기 로딩만 구현했다.
- W01~W02: 실제 최소화·복원 및 전역 단축키 충돌과 숨기기/표시의 포커스.

- W06~W08: 실제 다중 모니터·배율 변경·모니터 분리·OS 스냅과 리사이즈.

## 확정한 세부사항

- 기본 불투명도 75%, 새 이미지 전체 맞춤, 시작 및 재시작 편집 OFF.
- 상단 바 높이 112 DIP, 최소 폭 520 DIP, 본문 최소 높이 120 DIP. 작은 폭에서도 두 줄 제어와 상태줄로 핵심 버튼을 유지한다.
- 두 창은 네이티브 물리 좌표로 맞추며, 이미지 실제 배율은 화면 픽셀 기준으로 계산한다.
- 편집 ON과 불투명도 0%가 겹치면 입력 영역을 유지하기 위한 최소 알파 1/255가 남는다. OFF의 0%는 완전 투명이다.
- 수동 배율의 숫자와 이미지 이동량은 저장하지 않는다. 마지막 모드가 수동이면 재실행 시 전체 맞춤으로 복원한다.
- 전역 키는 Ctrl+Alt+R(숨기기/표시), Ctrl+Alt+E(편집 토글). 충돌 시 Ctrl+Shift+F12/F11을 시도하고 도움말에 실제 등록 결과를 표시한다.
- 외부 테스트 라이브러리 대신 앱의 명시적 `--self-test <보고서 경로>`로 WPF와 네이티브 연동을 함께 검사한다.
- PNG/JPEG/BMP 정지 이미지만 지원한다. 파일 256 MB, 9,600만 픽셀로 제한한다.
- 공개 저장소에 개인 이미지·로컬 설정·빌드 산출물·인증 정보를 포함하지 않는다. 오픈소스 라이선스는 아직 지정하지 않았다.
