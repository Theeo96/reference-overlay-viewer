# 레퍼런스 이미지 뷰어 검증 항목

아래는 실제 사용자 조작 기준의 수용 검사 절차다. 사용자의 요청으로 Computer Use 직접 검증은 **미실행**이다. 자동 검사에서 확인한 부분과 남은 수동 항목은 VERIFICATION.md를 참고한다. 자동 계산 검사를 실제 데스크톱 조작 통과로 해석하지 않는다.

## 검증 환경과 자료

- Windows 버전, .NET 버전, 화면 해상도와 배율, 모니터 수를 기록한다.
- 정사각형·가로형·세로형 이미지, 알파 PNG, EXIF 회전 JPEG, 큰 이미지, 손상 파일을 준비한다. 공개 저장소에는 자작 또는 재배포 가능한 자료만 넣는다.
- 뒤 작업창으로 메모장과 스크롤 가능한 브라우저 페이지 등 별도 프로세스를 사용한다.
- 타이핑, 선택 드래그, 휠 검증은 해당 작업이 가능한 뒤 앱 영역에서 실시한다. 휠 정책은 Windows의 비활성 창 스크롤 설정 등도 함께 기록한다.

## 핵심 모드와 입력

| ID | 절차 | 기대 결과 |
| --- | --- | --- |
| M01 | OFF, 본문 50%로 뒤 메모장 텍스트 클릭 후 타이핑 | 메모장이 활성화되어 글자가 입력되고 뷰어 포커스 변화 없음 |
| M02 | OFF, 이미지 영역 위에서 뒤 메모장 텍스트 선택 드래그 | 뒤 텍스트만 선택되고 이미지 및 뷰어 위치는 유지 |
| M03 | OFF, 본문 위에서 뒤 페이지 휠 스크롤 | 뒤 앱의 일반 스크롤 정책대로 동작, 뷰어 배율 변화 없음 |
| M04 | OFF, 상단 바 클릭 및 빈 영역 드래그 | 뷰어 활성화 가능, 상단과 본문이 함께 이동 |
| M05 | OFF, 본문 모서리·테두리·빈 여백 클릭/드래그 | 뷰어 리사이즈 없음, 뒤 창이 입력을 받음 |
| M06 | ON에서 본문 휠과 드래그 | 뷰어 배율 및 이미지 이동만 변경, 뒤 앱에는 전달되지 않음 |
| M07 | ON에서 창 모서리 리사이즈 | 창 크기가 변하고 두 창이 정확히 붙어 있음 |
| M08 | ON→OFF→ON 반복 | 배율·이동량·창 크기 보존, 토글 표시와 실제 입력 정책 일치 |
| M09 | 드래그 중 단축키 등 구현된 경로로 OFF 전환 | 캡처 해제, 남은 입력이 뷰어에 갇히지 않음 |
| M10 | OFF 상단 바 클릭 후 본문을 통해 뒤 앱 클릭 | 뒤 앱이 정상 활성화되고 계속 작업 가능 |
| M11 | OFF에서 열기·불투명도·이동·닫기 조작 | 해당 조작은 가능, 배율·맞춤·크기 편집 제어는 비활성 |

## 표시와 이미지 크기

| ID | 절차 | 기대 결과 |
| --- | --- | --- |
| V01 | 불투명도 0/50/100% | 본문 전체가 바뀌고 상단 바는 계속 불투명하며 클릭 가능 |
| V02 | 다른 일반 창을 활성화하고 이동 | 뷰어가 위에 유지되며 배경 앱 활성화를 방해하지 않음 |
| V03 | 전체 맞춤으로 세 가지 종횡비 이미지 표시 | 이미지 전체가 본문 안에 들어오고 비율 유지 |
| V04 | 가로 맞춤 후 ON에서 위아래 이동 | 이미지 폭이 본문 폭과 일치, 넘친 세로 부분 탐색 가능 |
| V05 | 세로 맞춤 후 ON에서 좌우 이동 | 이미지 높이가 본문 높이와 일치, 넘친 가로 부분 탐색 가능 |
| V06 | 100% 표시, 화면 배율 100/150/200% | 원본 1픽셀과 화면 1픽셀 대응 정책이 유지됨 |
| V07 | 맞춤 상태에서 창 크기 변경 | 선택한 맞춤 정책대로 재계산 |
| V08 | 수동 배율에서 창 크기 변경 | 배율 유지, 가능한 범위에서 시야 중심 유지 |
| V09 | 포인터를 이미지 한 지점에 놓고 휠 확대 | 해당 지점 기준 확대, 맞춤에서 수동으로 전환 |
| V10 | 배율 입력에 0/음수/문자/범위 밖 입력 | 오류 처리 또는 제한, 앱 상태 보존 |
| V11 | 이미지를 가장자리까지 이동 후 중앙 정렬/전체 맞춤 | 이미지가 복구되고 조작 불가능하게 사라지지 않음 |

## 파일과 수명 주기

| ID | 절차 | 기대 결과 |
| --- | --- | --- |
| F01 | 정상 PNG/JPEG/BMP 열기 및 교체 | 표시 성공, 알파와 EXIF 회전 반영 |
| F02 | 파일 선택 취소 또는 손상/미지원 파일 열기 | 기존 이미지 유지, 필요한 오류 안내, 종료되지 않음 |
| F03 | 이미지 표시 후 원본 파일 이름 변경/삭제 | 뷰어가 파일 잠금으로 막지 않음 |
| F04 | 큰 이미지 열기 및 여러 번 교체 | UI 응답성 유지, 지속적인 비정상 메모리 증가 없음 |
| W01 | 상단 바 최소화 후 작업표시줄 복원 | 두 영역이 함께 사라지고 복원, 항목 중복 없음 |
| W02 | 빠른 숨기기/표시 단축키 반복 | 두 영역이 함께 숨고 복원되며 뒤 작업 포커스 유지 |
| W03 | 두 모드에서 닫기 | 보조창, 프로세스, 전역 단축키가 남지 않음 |
| W04 | 설정 변경 후 재실행 | 위치·크기·불투명도 등 복원, 편집 모드는 OFF |
| W05 | 마지막 파일 삭제/설정 손상 후 실행 | 빈 상태 또는 기본값으로 실행 가능 |
| W06 | 배율이 다른 모니터 사이 이동 및 크기 변경 | 상단 바/본문 이음새와 클릭 영역 일치 |
| W07 | 모니터 분리 후 재실행 | 창이 접근 가능한 화면 안으로 복구 |
| W08 | 좁은 창과 최소 크기 사용 | 상단 바 핵심 버튼 및 드래그 영역 사용 가능 |
| W09 | SDK 없는 대상 환경에서 배포물 실행 | 정상 시작 및 핵심 기능 작동 |

## 결과 기록 양식

```text
검증일 / 커밋:
Windows / .NET / 모니터와 배율:
항목 ID:
결과: 통과 / 실패 / 미검증
실제 관찰:
재현 절차 또는 남은 제약:
```

스크린샷은 외형 확인 자료다. 클릭 통과와 포커스의 증거로는 실제 입력 결과와 관찰 내용을 함께 기록한다.
