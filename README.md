# Reference Overlay Viewer

Windows에서 다른 프로그램 위에 참고 이미지를 겹쳐 두고 사용하는 데스크톱 이미지 뷰어입니다. 한국어 표시 이름은 **레퍼런스 이미지 뷰어**입니다.

상단 바는 항상 불투명하고 조작할 수 있습니다. 이미지 영역은 불투명도를 조절할 수 있으며, 편집 모드를 끄면 마우스 입력이 아래 작업창으로 통과합니다. 편집 모드를 꺼도 상단 바를 드래그해 뷰어 전체를 이동할 수 있습니다.

## 현재 상태

2026-11-19 KST: v0.1.0 구현. 편집 모드, 불투명도, 이미지 맞춤·확대·이동, 창 크기 조절, 설정 복원과 전역 단축키를 제공합니다. Release 빌드와 창을 표시하지 않는 자동 회귀 검사를 수행했습니다. 사용자의 요청에 따라 Computer Use를 이용한 실제 마우스·포커스 및 다중 모니터 수동 검증은 수행하지 않았습니다. 자세한 결과는 [검증 결과](docs/VERIFICATION.md)에 있습니다.

## 실행과 사용

로컬 빌드 결과가 있다면 프로젝트 루트의 `실행하기.cmd` 또는 `artifacts/win-x64/ReferenceOverlayViewer.exe`를 실행합니다. 배포 ZIP은 `artifacts/ReferenceOverlayViewer-win-x64.zip`입니다. ZIP을 새 폴더에 풀고 exe를 실행하면 됩니다. 실행 시 관리자 권한은 필요하지 않습니다.

1. 상단 **열기**로 PNG/JPG/BMP를 선택합니다. 이미지 파일 경로를 실행 인자로 전달할 수도 있습니다.
2. **편집 모드 ON**에서 휠로 확대·축소하고 이미지 드래그로 내부 위치를 바꿉니다. 테두리·모서리를 드래그하면 창 크기가 변합니다.
3. 전체/가로/세로 맞춤 또는 실제 크기를 선택합니다. 배율은 숫자 입력 후 Enter로 적용하며 수동 범위는 5~1600%입니다. 맞춤 모드는 이 범위 밖에서도 정확히 맞춥니다.
4. **편집 모드 OFF**로 바꾸면 본문 클릭·드래그·휠이 뒤 작업창으로 통과하도록 Windows 창 스타일이 전환됩니다. OFF에서는 배율·맞춤 제어가 비활성화됩니다.
5. 상단 바 빈 부분의 드래그 이동과 열기·불투명도 조절은 두 모드 모두 가능합니다.

| 단축키 | 동작 |
| --- | --- |
| Ctrl+Alt+R | 뷰어 숨기기/표시 |
| Ctrl+Alt+E | 편집 모드 ON/OFF |
| Esc | 뷰어에 포커스가 있을 때 편집 OFF |
| Ctrl+O | 상단 바에 포커스가 있을 때 이미지 열기 |

전역 단축키 충돌 시 각각 Ctrl+Shift+F12, Ctrl+Shift+F11을 시도합니다. 실제 등록된 키 또는 실패 상태는 상단 도움말에서 확인할 수 있습니다. 숨기기와 최소화는 별개이며, 최소화한 창은 작업표시줄에서 복원합니다.

## 빌드와 자동 검증

Windows x64와 .NET 10 SDK가 필요합니다. 외부 NuGet 라이브러리는 사용하지 않습니다. 프로젝트 내부 `.local/dotnet`에 SDK가 있으면 스크립트가 자동으로 사용하며, 없으면 PATH의 dotnet을 사용합니다.

```powershell
./scripts/build.ps1            # Release 빌드와 창을 띄우지 않는 자동 검사
./scripts/build.ps1 -Publish   # 자체 포함 Windows x64 exe 및 ZIP 생성과 패키지 검사
```

자동 검사는 `artifacts/self-test.json`, 패키지 검사는 `artifacts/published-self-test.json`에 저장됩니다. 상단 바의 화면 밖 렌더링 결과는 `artifacts/toolbar-520.png`, `toolbar-760.png`입니다. 테스트는 개인 설정을 읽거나 바꾸지 않고, 창을 표시하거나 전역 단축키를 등록하거나 데스크톱 입력을 합성하지 않습니다. GitHub Actions에서도 같은 빌드·검사·패키징 절차를 실행합니다.

배포 exe는 .NET 런타임을 포함합니다. SDK와 런타임을 따로 설치할 필요가 없도록 빌드하며, 첫 실행 시 네이티브 라이브러리를 사용자 임시 폴더에 추출할 수 있습니다. 새 PC에서의 호환성 검증은 별도입니다. ARM64 및 독점 전체화면 위 표시를 보장하지 않습니다.

## 설정과 제한

설정은 `%LOCALAPPDATA%/ReferenceOverlayViewer/settings.json`에 저장됩니다. 창 위치·크기·불투명도·맞춤 방식·마지막 이미지 경로를 기억합니다. 편집 모드는 매 실행 OFF입니다. 마지막 수동 배율의 숫자와 이미지 이동량은 저장하지 않으며, 이전 상태가 수동 배율이면 재실행 시 전체 맞춤으로 복원합니다. 설정 파일을 삭제하면 기본값으로 돌아갑니다.

원본 이미지는 수정하지 않으며, 디코딩 후 파일 잠금을 해제합니다. 제한은 파일 256 MB, 해상도 9,600만 픽셀입니다. 이미지 디코딩은 백그라운드에서 수행하며 실패 시 기존 이미지를 유지하고 상단 상태줄에 오류를 표시합니다. 편집 ON과 불투명도 0%가 동시에 적용되면 입력 영역을 유지하기 위한 최소 알파 1/255가 남습니다. OFF의 0%는 완전히 투명합니다.

정지 이미지 한 장을 대상으로 합니다. 여러 창, 갤러리, 애니메이션, WebP 등은 이번 범위에 포함하지 않습니다. 일반 Windows 10/11 x64용으로 구현했으며 실제 수동 검증이 남아 있습니다. 공개 저장소에 개인 이미지나 설정을 올리지 않습니다. 오픈소스 라이선스는 아직 별도로 지정하지 않았습니다.

## 기술 방향

C#과 WPF, Win32 API를 사용합니다. 불투명 상단 제어창과 반투명 이미지 표시창을 분리하고 물리 화면 좌표로 위치를 동기화합니다. 이미지 창은 layered window이며 OFF에서 WS_EX_TRANSPARENT와 WS_EX_NOACTIVATE를 적용합니다. SDK는 10.0.404, 런타임은 10.0.15로 빌드했습니다. [.NET 10 LTS 지원 정책](https://dotnet.microsoft.com/en-us/platform/support/policy)을 확인하고 버전을 선택했습니다.
